# Learn

Get started with OneTool and master its capabilities.

This section covers everything from installation to advanced usage patterns. Whether you're new to OneTool or looking to deepen your expertise, you'll find guides and examples to help you succeed.

- [MCP Proxy](mcp-proxy.md) — any external MCP server becomes a callable Python namespace, with automatic name-aliasing and runtime enable/disable/restart control.
- [Code Harness Routing](code-routing.md) — launch Claude Code or Codex through exact proxy routes or direct Codex profiles.
- [LLM Routing](llm-routing.md) — route generation through explicit CLIProxyAPI or direct backends while keeping embeddings and native grounding isolated.
- [Demos](demos/index.md) — scripted, narrated, replayable demonstrations of OneTool's differentiating capabilities.
